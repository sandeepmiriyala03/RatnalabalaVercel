## ఇది ఎలా మొదలైంది

మా తాతగారు మిరియాల వెంకటరత్నం గారు రాసిన పద్యాలు ఒక పాత పుస్తకంలో ఉండేవి. అవి కాలంతో పాటు కనుమరుగు కాకూడదని, నలుగురికీ చేరాలని మొదలుపెట్టిన చిన్న ప్రయత్నమే ఈ సైట్. ఆ 34 పద్యాలతో మొదలై, ఈ రోజు శతకాలు, కథలు, వ్యాకరణం, భగవద్గీత, పిల్లల అక్షరాల వరకు పెరిగింది.

ఇది వ్యాపారం కాదు, ఒక అభిరుచి. ఇక్కడ చదవడానికి, వినడానికి ఎవరూ డబ్బు కట్టనక్కర్లేదు. ప్రతి విభాగాన్ని ఒక "మాల" అని పిలుస్తాం — ఒక్కో మాల ఒక్కో అంశం.

మా పాఠకుల్లో చాలామంది పెద్దవాళ్ళు. అందుకే సైట్ అంతటా అక్షరాలు పెద్దగా, బటన్లు వేలితో సులభంగా నొక్కేలా, రంగులు కళ్ళకు స్పష్టంగా (WCAG AAA స్థాయి) ఉండేలా జాగ్రత్త పడ్డాం.

## సాహిత్యం

### 📜 పద్యాలమాల (రత్నాలబాల)
మా తాతగారు మిరియాల వెంకటరత్నం గారి పద్యాల సంకలనం — **34 పద్యాలు.** ప్రతి పద్యాన్ని చదవవచ్చు, మగ / స్త్రీ స్వరంలో వినవచ్చు.

**భావాలమాల (పద్య అన్వేషణ)** — గుర్తున్న ఒక మాట, భావం లేదా సంఖ్య చెబితే చాలు, సరైన పద్యం వెతికి పెడుతుంది. ఉదా: `jan 10`, `సుమతి 5`, `దయ`, `1`. ఇది మాట కాదు, *అర్థం* ఆధారంగా వెతుకుతుంది — "అమ్మ ప్రేమ" అని అడిగితే ఆ మాట లేకపోయినా ఆ భావం ఉన్న పద్యాలు వస్తాయి.

### ✍️ మిరా పద్యాలు
మా నాన్నగారు డాక్టర్ మిరియాల రామకృష్ణ గారి పద్యాలు. ప్రస్తుతం **3 పద్యాలు** — ఇంకా చేరుస్తున్నాం.

### 📿 శతకాలమాల
ప్రసిద్ధ తెలుగు శతకాలు ఒకే చోట — **10 శతకాలు, 1037 పద్యాలు.** ప్రతి పద్యాన్ని MP3 (వినడానికి), MP4 (వీడియో), PNG (చిత్రం) గా పొందవచ్చు.

### 🌿 పరాభవమాల — ఉగాది శతకం
పరాభవ నామ సంవత్సరానికి స్వాగతం పలుకుతూ రాసిన **108 పద్యాలు.** ప్రతి పద్యం "రా ఉగాది" మకుటంతో ముగుస్తుంది. పరాభవం అంటే ఓటమి కాదు — *పర-భవం*, అంటే సరికొత్త, ఉన్నతమైన ఉనికి అని ఈ శతకం చెబుతుంది.
- సృజన: Claude Opus 4.6 · మానవ సహకారం: దిలీపు మిరియాల · యంత్ర సహకారం: చందం AI పరికరాలు

### 📖 కథామాల
పిల్లల కోసం నీతి విలువలున్న చిన్న తెలుగు కథలు — **130 కథలు, 4 వయసు గుంపులుగా.**

### 🌸 స్మృతిమాల — పింగళి సీతమామ కథలు
చిన్ననాటి జ్ఞాపకాల ఆధారంగా, AI సహాయంతో రాసిన కథల సిరీస్. ఇప్పుడు కొత్త రూపంలో:
- **పూసల దండ లాంటి కథల వరుస** — ఏ కథ నుంచైనా ఏ కథకైనా ఒక్క నొక్కుతో
- **"చదివి వినిపించు"** — కథను గట్టిగా చదువుతుంది; చదువుతున్న పేరా రంగులో వెలుగుతుంది; ఆపవచ్చు, వేగం మార్చుకోవచ్చు
- **ఎక్కడ ఆపారో గుర్తుంచుకుంటుంది** — మళ్ళీ వచ్చినప్పుడు అక్కడి నుంచే
- **చదివినవాటికి ✓ గుర్తు, నచ్చిన కథకు రేటింగ్**
- **కథను పోస్టర్‌గా** — WhatsApp కి నేరుగా పంపవచ్చు
- **కథల పట్టిక** — మా సొంత Yuktai Grid తో (సాంకేతికత భాగం చూడండి)

### 📚 నా చదువు
మీరు చదివిన పద్యాలు, కథలు, మీకు నచ్చినవి (♥) ఒకే చోట. ఏ మాలలోనైనా పైన ఉన్న ♥ నొక్కితే ఇక్కడ చేరుతుంది. ఇది మీ ఫోన్ / కంప్యూటర్‌లోనే ఉంటుంది, మాకు రాదు.

### 🕉️ గీతామాల
భగవద్గీత శ్లోకాలు — చదవండి, వినండి.

### 📰 వాచకమాల
తెలుగు వార్తలు చదవడానికి, వినడానికి. కళ్ళు అలసిపోతే, వార్తను చదివి వినిపిస్తుంది.

### 🧩 సమాసమాల

## సృష్టించండి, పంచుకోండి

### ✒️ ఖతిమాల — తెలుగు పత్రాలు, పోస్టర్లు, స్లైడ్ షోలు *(కొత్త రూపం)*
మొదట్లో ఇది ఒక పాఠ్య పెట్టె, ఫాంట్ ఎంపిక మాత్రమే. ఇప్పుడు Word, PowerPoint లాగే — కానీ తెలుగు కోసం, సులభంగా.

- **పెట్టెలుగా రాయడం:** శీర్షిక, పేరా, పద్యం, జాబితా, పట్టిక, మీ ఫోటో, అలంకరణ గీత, కొత్త పేజీ
- **ఒక్కో పెట్టెకు Word లాంటి అలంకరణ:** ఫాంట్, సైజు, **B** *I* <u>U</u>, ఎడమ / మధ్య / కుడి / సమం, రంగు, పంక్తి దూరం
- **10 రూపాలు:** తెల్ల కాగితం, తాళపత్రం, పండుగ తోరణం, నీలాకాశం, పచ్చని పొలం, వెన్నెల రాత్రి, బంగారు అంచు, పట్టు అంచు, ఆధునిక, గులాబీ తోట
- **పరిమాణాలు:** A4 (ప్రింట్), చతురస్రం (Instagram / Facebook), స్టోరీ (WhatsApp స్టేటస్), 16:9 (TV)
- **5 సిద్ధ నమూనాలు:** ఖాళీ పత్రం, పద్య పోస్టర్, శుభాకాంక్షలు, వ్యాసం, స్లైడ్ షో
- **స్లైడ్ షో:** "ఎన్ని స్లైడ్లు?" అని చెబితే, మీ పత్రాన్ని అన్ని స్లైడ్లుగా తానే పంచుతుంది. పూర్తి తెరలో, **మీ పాటతో** నడుస్తుంది
- **డౌన్‌లోడ్:** PDF · పోస్టర్ చిత్రం · Word · PowerPoint — **మీరు ఎంచుకున్న ఫాంట్ ప్రతి ఫైల్‌లోనూ అలాగే.** Word ఫైల్‌లో ఫాంట్ లోపలే ఉంటుంది, కాబట్టి ఎదుటివారి కంప్యూటర్‌లో ఆ ఫాంట్ లేకపోయినా అదే రూపం
- **ఫోన్‌లో WhatsApp కి నేరుగా** పంపే బటన్
- **↶ వెనక్కి / ↷ ముందుకు** — పొరపాటైనా భయం లేదు
- **ఆటో సేవ్** — చిత్రాలు, పాటతో సహా మీ పరికరంలోనే. ఏదీ సర్వర్‌కి వెళ్ళదు, ఏ AI కీ పంపము

### 🖼️ చిత్రమాల — పద్య యంత్రం
పద్యం రాయండి → చిత్రంగా మార్చండి → పంచుకోండి.

**ఎలా:** కవి పేరు → పాదాల సంఖ్య (1–8) → ప్రతి పాదం టైప్ చేయండి → శీర్షిక → "పోస్టర్ చూపించండి" → ఫాంట్, రూపం మార్చి డౌన్‌లోడ్. Canva లాగా అక్షరాలను జరపవచ్చు, కొత్త పెట్టెలు చేర్చవచ్చు. మీరు రాసింది సర్వర్‌లో సేవ్ కాదు.

### 🎙️ స్వరమాల
మాట్లాడండి లేదా టైప్ చేయండి → సరిచేయండి → ఫాంట్, రూపం ఎంచుకోండి → వినండి → పోస్టర్ డౌన్‌లోడ్ చేయండి.
**స్వరమాల రేడియో** — పద్యాలను ఒకదాని తర్వాత ఒకటి వరుసగా వినిపిస్తుంది, రేడియో లాగా.

### 🔍 లిపిమాల — తెలుగు OCR
ఫోటోలోని లేదా పాత పుస్తకంలోని తెలుగు అక్షరాలను టైప్ చేసిన పాఠ్యంగా మారుస్తుంది. పాత పుస్తకాలను డిజిటల్‌గా దాచుకోవడానికి, చేతిరాతను టెక్స్ట్‌గా మార్చడానికి.

**ఎలా:** చిత్రం అప్‌లోడ్ → "OCR విశ్లేషణ" → పాఠ్యం వస్తుంది → సరిచేయండి → శైలి మార్చండి → చిత్రంగా డౌన్‌లోడ్.

### 🔊 ధ్వనిమాల · 🎨 దర్శనమాల · 🎬 కళామాల
ప్రతి పద్యానికి — ఆడియో (ధ్వనిమాల), పోస్టర్ (దర్శనమాల), MP4 వీడియో (కళామాల).

### ❓ PDF ప్రశ్నోత్తరి *(కొత్తది)*
మీ దగ్గర ఉన్న తెలుగు PDF అప్‌లోడ్ చేసి, దాని గురించి ప్రశ్నలు అడగండి. జవాబు **ఆ PDF లోంచే**, ఏ పేజీలో ఉందో సంఖ్యతో సహా వస్తుంది.

- దీని కోసం మేమే సొంతంగా ఒక వెతికే పద్ధతి (RAG) రాశాం — మీ PDF ఏ బయటి AI కంపెనీకీ వెళ్ళదు
- PDF ని ఎలా ముక్కలుగా విభజించామో, ప్రతి ముక్కకు ఎంత మార్కు వచ్చిందో, జవాబు ఎక్కడి నుంచి తీశామో — అన్నీ తెరపై చూపిస్తాం. ఏదీ దాచము
- టైప్ చేసిన తెలుగు PDF లు మాత్రమే. స్కాన్ చేసిన బొమ్మల PDF, ప్రమాదకరమైన code ఉన్న PDF లను ముందే గుర్తించి, ఎందుకు తీసుకోలేదో తెలుగులో చెబుతుంది
- PDF ఫైల్ సేవ్ కాదు; దాని పాఠ్యం 24 గంటల్లో తొలగిపోతుంది

### 🧭 నిర్ణయాత్మక మాల — ఈ రోజు ఏ పద్యం?
1,140+ పద్యాల నిధి నుంచి మీ మనసుకు తగిన పద్యాన్ని ఎంచి, *ఎందుకు* ఆ పద్యం ఎంచిందో కారణం కూడా చెబుతుంది.
- ప్రతి పద్యం శివభక్తి, కృష్ణభక్తి, రామనామ మహిమ, గురు స్తుతి, లోకనీతి, తెలుగు భాషాభిమానం — దేనికి చెందినదో గుర్తిస్తుంది
- హాస్యం నుంచి భక్తి వరకు, ప్రతిసారి కొత్తది
- నచ్చిన పద్యాన్ని పోస్టర్‌గా పొందవచ్చు

### 🗝️ విదురమాల — రహస్య భాష
మహాభారతంలో లక్క ఇంటి కుట్ర నుంచి పాండవులను కాపాడడానికి విదురుడు ధర్మరాజుతో సంకేత భాషలో మాట్లాడాడు:

> "ఖనన శిల్పకళా ప్రౌఢుఁడనఘ!... నడవి కార్చిచ్చు గాల్చుచో నందు నక్క బిలము సొచ్చిన యలుక గాలక సుఖించు."

ఆ స్ఫూర్తితో "క" శైలి రహస్య భాష: ప్రతి అక్షర శబ్దానికి ముందు 'క' చేరుతుంది, మధ్యలో ఖాళీ వస్తుంది.
ఉదా: **రాముడు ➔ కరా కము కడు**

### 🎨 శైలిమాల
తెలుగు లిపికి యూనికోడ్ ఓపెన్‌టైప్ సాంకేతికతను జోడించి ఫాంట్లను ఉచితంగా అందించిన అప్పాజీ అంబరీష గారికి, FreeTeluguFonts.com కి, ఇతర ఫాంట్ రూపకర్తలందరికీ రత్నాలబాల–జ్ఞానమాల తరపున హృదయపూర్వక ధన్యవాదాలు. వారు లేకపోతే ఈ సైట్‌లో ఇన్ని అందమైన తెలుగు అక్షరాలు ఉండేవి కావు.

### 🧩 Yuktai Grid (యుక్తి AI పట్టిక) — మా సొంత library
యుక్తిశాల AI తయారుచేసిన తెలుగు పట్టిక (grid) — `@yuktishaalaa/yuktai`. కథలు, పద్యాలు, అక్షరాలు, నియమాల జాబితాలను పట్టికగా చూపించి — వెతకడానికి, వరుస మార్చడానికి, **PDF, Excel** గా డౌన్‌లోడ్ చేసుకోవడానికి వీలు కల్పిస్తుంది.

**ఎందుకు సొంతంగా?** బయటి పట్టికలు ఇంగ్లీష్ కోసం తయారైనవి. తెలుగు గుణింతాలు, వత్తులు సగానికి కత్తిరించడం, అక్షర క్రమం (అ, ఆ, ఇ…) తప్పుగా వరుస పెట్టడం, PDF లో తెలుగు అక్షరాలు పెట్టెలుగా రావడం — ఇవన్నీ మేము చూశాం. పెద్దవాళ్ళకు చిన్న అక్షరాలు, చిన్న బటన్లు మరో సమస్య. అందుకే తెలుగును, పెద్దవాళ్ళను దృష్టిలో పెట్టుకుని మేమే రాశాం.

**సైట్‌లో ఎక్కడెక్కడ ఉంది:** మాలల్లో **"యుక్తి AI"** లేదా **"యుక్తి AI పట్టిక"** అనే ట్యాబ్ కనిపిస్తే — అదే Yuktai Grid.

| పద్యాలమాల · మిరా పద్యాలు | అన్ని పద్యాలు — పేరు నొక్కితే ఆ పద్యం కార్డుకు |

ఒకే పద్యంలో తెలుగు అచ్చులన్నీ వరుసగా వస్తాయి — మన భాష ఎంత అందమైనదో చెప్పడానికి ఇంతకంటే మంచి ఉదాహరణ లేదు. అందుకే ఈ పద్యం మా సైట్‌కు ఒక చిహ్నం లాంటిది.

## ప్రతి పేజీని ఎలా ఉపయోగించాలి — మొదటి అడుగు నుంచి చివరి దాకా

ఏ పేజీ ఎక్కడ తెరవాలి, ఏ బటన్ ఎప్పుడు నొక్కాలి, వచ్చిన ఫలితాన్ని ఎలా చదవాలో, ఎలా దాచుకోవాలో ఈ భాగంలో వరుసగా చెప్పాం. బటన్ పేర్లు సైట్‌లో కనిపించే తెలుగు పేర్లకు దగ్గరగానే ఇచ్చాం. ఫోన్‌లో కొన్ని పేర్లు బొమ్మలు (చిహ్నాలు) గా మాత్రమే కనిపించవచ్చు.

### ముందుగా సైట్‌ను మీకు అనుకూలంగా చేసుకోండి

1. [రత్నాలబాల – జ్ఞానమాల](https://ratnalabala.vercel.app/) తెరవండి.
2. **ఫాంట్ నియంత్రణల**తో తెలుగు ఫాంట్, అక్షరాల పరిమాణం ఎంచుకోండి. చదువుతూనే మార్చుకోవచ్చు; మీ ఎంపిక అన్ని పేజీలకూ వర్తిస్తుంది.
3. పైన ఉన్న **☰ మెనూ** నొక్కి సాహిత్యం / వ్యాకరణం / కళలు వంటి గుంపును తెరవండి. మెనూలోని వెతుకుడు గడిలో మాల పేరు టైప్ చేసి కూడా వెళ్ళవచ్చు.
4. కళ్ళకు హాయిగా ఉండేలా **లైట్ / డార్క్** బటన్‌తో రంగులు మార్చుకోండి. పొడవైన పేజీలో కిందికి వెళ్ళాక కనిపించే **పైకి** బటన్ మిమ్మల్ని పేజీ మొదటికి తీసుకెళ్తుంది.
5. మాల పేరు పక్కన లేదా ఏ అంశం పక్కనైనా ఉన్న **♥** నొక్కితే అది *నా చదువు*లో ఇష్టమైనదిగా చేరుతుంది. పేజీకి చిన్న సహాయం ఉంటే **“ఈ పేజీ ఎలా వాడాలి?”** తెరిచి చూడండి.

### అన్ని పేజీల్లో ఉండే సహాయకాలు

- **భావాలమాల AI (ఎడమ వైపు బటన్):** నొక్కి మీ ప్రశ్న రాసి పంపండి. జవాబు చదివాక కిటికీ మూసి పేజీకి తిరిగి రండి.
- **జ్ఞానశోధన (కుడి వైపు బటన్):** పదం లేదా ప్రశ్న టైప్ చేసి **వెతకండి** నొక్కండి. WebMCP లేని బ్రౌజర్‌లోనూ సాధారణ శోధన పనిచేస్తుంది; WebMCP ఉందో లేదో ప్యానెల్‌లోనే కనిపిస్తుంది.
- **యాప్‌ను ఇన్‌స్టాల్ చేయండి:** ఈ ఆహ్వానం కనిపిస్తే నొక్కి, బ్రౌజర్ చూపే నిర్ధారణ దశలు పూర్తి చేయండి. మీ బ్రౌజర్ / ఫోన్ అనుమతిస్తేనే ఇది కనిపిస్తుంది.
- **🧩 యుక్తి AI పట్టిక (Yuktai Grid):** చాలా మాలల్లో **"యుక్తి AI"** అనే ట్యాబ్ ఉంటుంది. అన్నిచోట్లా ఒకేలా వాడండి:
  1. ట్యాబ్ నొక్కితే ఆ మాలలోని అంశాలన్నీ పట్టికగా వస్తాయి.
  2. పైన ఉన్న **వెతుకుడు** గడిలో పేరు, పదం లేదా అక్షరం టైప్ చేస్తే, సరిపోయే వరుసలు మాత్రమే మిగులుతాయి.
  3. నిలువు వరుస **శీర్షిక**ను నొక్కితే ఆ వరుస ప్రకారం క్రమం మారుతుంది — మళ్ళీ నొక్కితే తిరగబడుతుంది.
  4. ఫోన్‌లో పట్టిక వెడల్పుగా ఉంటే వేలితో **పక్కకు జరపండి**.
  5. వరుసలో పేరు / లింక్ నొక్కితే ఆ అంశం పూర్తి పేజీకి (లేదా కార్డుకు) తీసుకెళ్తుంది.
  6. **PDF** లేదా **Excel** బటన్‌తో — మీరు వెతికి తగ్గించిన జాబితానే — ఫైల్‌గా దాచుకోవచ్చు, ప్రింట్ తీసుకోవచ్చు.
- **కింది పట్టీ (footer):** ప్రతి పేజీ అడుగున ఒకే వరుసలో "© యుక్తిశాల AI · సందర్శనల సంఖ్య" కనిపిస్తుంది. ఫోన్‌లో టైప్ చేసేటప్పుడు ఇది తానే దాక్కుంటుంది.

3. పద్యం, కథ, అక్షరం, సామెత లేదా శ్లోకం వెతకండి; లింక్ ఉన్న వరుస నొక్కితే పూర్తి పేజీకి వెళ్తుంది.
4. **PDF / Excel** బటన్లతో జాబితా దాచుకోండి. నెట్ నెమ్మదిగా ఉంటే కావలసిన మాలనే ముందు తెరవండి — పెద్ద డేటా అవసరమైనప్పుడే వస్తుంది.

#### PDF ప్రశ్నోత్తరి — [PDF గురించి అడగండి](https://ratnalabala.vercel.app/pdf-prashnottari)

1. **PDF అప్‌లోడ్**తో గరిష్ఠం 4 MB, టైప్ చేసిన తెలుగు పాఠ్యం ఉన్న PDF ఎంచుకోండి. స్కాన్ / బొమ్మలు మాత్రమే ఉన్నవి, పాస్‌వర్డ్ ఉన్నవి, పాత (యూనికోడ్ కాని) తెలుగు ఫాంట్‌తో ఉన్నవి, ప్రమాదకరమైన code ఉన్నవి తీసుకోదు — ఎందుకో తెలుగులో చెబుతుంది.
2. తనిఖీ ఫలితాలు చూడండి: తెలుగు అక్షరాల శాతం, పాఠ్యం నాణ్యత, పేజీల రకాలు, వదిలేసిన బొమ్మలు / ఖాళీ పేజీలు.
3. **పేజీ పటం**లో పేజీ నొక్కితే ఆ పేజీ ముక్కలు కనిపిస్తాయి. **పూర్తిగా చూడండి**తో ప్రతి ముక్క పూర్తి పాఠ్యం; ముందు ముక్క నుంచి కొనసాగిన భాగం (overlap) వేరే రంగులో ఉంటుంది.
4. సూచించిన ప్రశ్న నొక్కండి, లేదా **మీ ప్రశ్న** గడిలో తెలుగులో రాసి పంపండి.
5. జవాబుతో పాటు అది ఏ పేజీ నుంచి వచ్చిందో, ఏ ముక్కలు ఎంత సరిపోయాయో (మార్కులు) చూపిస్తుంది. PDF లో జవాబు లేకపోతే లేదని నిజాయితీగా చెబుతుంది.
6. పని అయ్యాక **తొలగించు** నొక్కండి. లేకపోయినా సర్వర్‌లోని పాఠ్యం 24 గంటల్లో తానే తొలగిపోతుంది. పేజీ తెరిచి ఉన్నంతసేపు refresh చేసినా కొనసాగించవచ్చు.

## 💻 ప్రాజెక్ట్‌ను కంప్యూటర్‌లో నడపడం (డెవలపర్ల కోసం)

1. Node.js **24.x** ఇన్‌స్టాల్ చేసి, repository ఫోల్డర్‌లో terminal తెరవండి.
2. `npm ci` తో dependencies ఇన్‌స్టాల్ చేయండి.
3. `.env.local` లో మీ deployment కు కావలసిన environment variables పెట్టండి. **ఏ API key నీ source code లో గానీ README లో గానీ రాయవద్దు.**
4. Development server:

   ```bash
   npm run dev
   ```

5. terminal చూపిన చిరునామాను బ్రౌజర్‌లో తెరవండి.
6. Production build: `npm run build` — ఇది ముందు BAML client ను generate చేసి, తర్వాత `next build --webpack` నడుపుతుంది (Serwist offline వల్ల webpack). `npm run start` ఆ build ను నడుపుతుంది.

> Build లో `.next` పాత ఫైళ్ళ వల్ల వింత TypeScript errors వస్తే: `Remove-Item -Recurse -Force .next` (Windows) లేదా `rm -rf .next` చేసి మళ్ళీ build చేయండి.
